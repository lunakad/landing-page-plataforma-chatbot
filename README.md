# Aprediendo Git & GitHub
- EStos son los pasos para iniciar con Git
## Paso 1
- Inicializar nuevo repositorio
```
git init
```
- Directorio de Trabajo donde se escribe el código
## Paso 2
- Enviar los nuevos archivos o archivos modificados al área de preparación
```
git add index.html
git add .
```
- El Area de preparaciónes donde se preparan los cambios

## Paso 3
- Registrar una descripción del cambio realizado
```
git commit -m "proyecto base"
```
# Github
```
git remote add origin https://github.com/repo/mi_repositorio.git
```
- Enviar los cambios al repositorio Remoto

```
git push origin master
```
